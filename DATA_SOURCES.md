# Data sources

The sleep-decoding experiments use publicly available research datasets. The data files and trained models are not currently included in this repository.

- **Bitbrain Open Access Sleep (BOAS)**: OpenNeuro dataset ds005555, version 1.1.3, DOI [10.18112/openneuro.ds005555.v1.1.3](https://doi.org/10.18112/openneuro.ds005555.v1.1.3). The source dataset metadata specifies CC0. See the [dataset repository](https://github.com/OpenNeuroDatasets/ds005555) for its description and citation information.
- **Sleep-EDF Database Expanded**, version 1.0.0: [PhysioNet project page](https://physionet.org/content/sleep-edfx/1.0.0/). PhysioNet distributes the database under the Open Data Commons Attribution License v1.0; consult the project page for its required citation and license details.

Other materials referenced by the project may have different terms. Refer to the original source and license before redistributing them.
