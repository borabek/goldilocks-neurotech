# Hackathon submission (Oxford NeuroTech Hackathon, 7-8 November 2026)

This folder keeps the hackathon version of the project as it was submitted: the start-here page,
the plan (revision 19), the support slides and handout, the demo, the build and QA reports, the
release manifests and the run logs.

Nothing here has been edited. The documents and the scripts in `tools/` were written for the
original flat layout of the repository, so the paths they name are the old ones
([`docs/LAYOUT.md`](../docs/LAYOUT.md) maps them). To rerun a tool exactly as it ran then, check
out commit `dad97a1`, the last one with that layout.

The research that continued after the event lives in the main folders of the repository; see the
top-level [`README.md`](../README.md).
